# Week 1 – Project Proposal

## Project Title

**Machine Learning-Based Prediction of Bioactivity for Early-Stage Drug Discovery Using Chemical Data**

## Overview

Week 1 focused on developing the project proposal and defining a structured computational workflow for predicting compound bioactivity using chemical and molecular data.

The proposed project aims to explore how **machine learning and data science approaches can be applied to chemical datasets** to identify patterns associated with compound bioactivity and support early-stage drug discovery research.

## Objective

The main objective was to design a computational workflow capable of:

* Collecting and organizing chemical and bioactivity data
* Cleaning and preprocessing the dataset
* Performing exploratory data analysis
* Selecting relevant molecular descriptors
* Developing predictive machine learning models
* Evaluating model performance
* Visualizing and interpreting the resulting patterns

## Proposed Workflow

The project was planned as a sequential data-science workflow:

```text
Data Collection
      ↓
Data Cleaning & Preprocessing
      ↓
Exploratory Data Analysis
      ↓
Feature Selection
      ↓
Predictive Modeling
      ↓
Model Evaluation
      ↓
Data Visualization & Interpretation
```

## Proposed Data Sources

The initial proposal considered publicly available chemical and bioactivity resources, including **ChEMBL** and **PubChem**, as potential sources of chemical and bioactivity information.

During the subsequent implementation stages of the internship, a **synthetic chemical-compound dataset** was used for the practical analysis.

## Proposed Molecular Features

The project focuses on molecular descriptors that can be used to characterize chemical compounds, including:

* Molecular Weight
* LogP
* Hydrogen Bond Acceptors (HBA)
* Hydrogen Bond Donors (HBD)
* Topological Polar Surface Area (TPSA)
* Rotatable Bonds

These descriptors provide numerical representations of molecular properties that can be analyzed using statistical and machine-learning methods.

## Machine Learning Approach

The proposed workflow included the development and comparison of multiple classification models for predicting compound bioactivity.

The planned models included:

* Logistic Regression
* Random Forest
* Support Vector Machine (SVM)

Model performance would be evaluated using appropriate classification metrics and visual analysis.

## Tools and Technologies

The project workflow was designed around:

* **Python**
* **Pandas**
* **NumPy**
* **Matplotlib**
* **Seaborn**
* **Scikit-learn**

## Expected Outcome

The proposed work was intended to demonstrate how chemical descriptors, exploratory analysis, machine learning, and visualization can be integrated into a computational workflow for bioactivity prediction.

The Week 1 proposal established the foundation for the practical work carried out during **Weeks 2–4**, covering data preprocessing and EDA, predictive modeling, and data visualization and interpretation.

## Week 1 Deliverable

**Project Proposal:** Machine Learning-Based Prediction of Bioactivity for Early-Stage Drug Discovery Using Chemical Data
