# Week 2 – Data Cleaning and Exploratory Data Analysis

## Overview

Week 2 focused on **data cleaning, preprocessing, statistical analysis, and exploratory data analysis (EDA)** using a synthetic chemical-compound dataset developed for the healthcare data science project.

The dataset contained **500 synthetic chemical compounds** with molecular descriptors representing chemical properties relevant to computational drug discovery and bioactivity analysis.

## Dataset

The dataset included the following molecular descriptors:

* Molecular Weight
* LogP
* Hydrogen Bond Acceptors (HBA)
* Hydrogen Bond Donors (HBD)
* Topological Polar Surface Area (TPSA)
* Rotatable Bonds
* Bioactivity classification

The bioactivity variable was represented using **Active** and **Inactive** classes.

## Data Cleaning and Preprocessing

The dataset was examined for common data-quality issues before analysis. The preprocessing workflow included:

* Checking for missing values
* Checking for duplicate records
* Reviewing data types
* Identifying potential outliers
* Verifying numerical feature distributions
* Preparing the dataset for exploratory analysis and subsequent modeling

## Exploratory Data Analysis

EDA was performed to understand the distributions and relationships among the molecular descriptors.

The analysis included:

* Descriptive statistical analysis
* Histograms for numerical variables
* Box plots for identifying potential outliers
* Scatter plots for examining relationships between descriptors
* Count plots for bioactivity classes
* Correlation heatmap for analyzing relationships among molecular descriptors

## Key Areas of Analysis

The analysis explored:

* Distribution of molecular weight
* Distribution of LogP
* Distribution of TPSA
* Distribution of HBA and HBD
* Rotatable-bond distributions
* Active versus inactive compound classes
* Relationships between molecular descriptors
* Correlations among chemical properties

## Tools and Technologies

* **Python**
* **Pandas**
* **NumPy**
* **Matplotlib**
* **Seaborn**
* **StandardScaler**

## Outcome

The Week 2 analysis established a cleaned and structured dataset for the next stages of the project. The exploratory analysis provided an initial understanding of molecular-property distributions, relationships between descriptors, and bioactivity-class patterns.

The findings from this stage supported the development of predictive models in **Week 3** and the visualization and interpretation work completed in **Week 4**.
